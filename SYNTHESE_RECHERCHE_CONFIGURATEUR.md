### Conclusion benchmark
**Aucun concurrent ne propose de configurateur en ligne pour les columbariums.**
Leader Granits est le seul à avoir un configurateur, mais limité aux monuments funéraires classiques.
→ **Opportunité de différenciation forte pour CIMTEA.**

## 5. Paramètres potentiels pour un configurateur Émeraude

Sur la base des informations collectées, voici les paramètres qui pourraient être configurables :

### Disposition / Layout
- Rectangulaire vs Angle (L)
- Nombre de modules de columbarium (1 ou 2 symétriques)

### Module columbarium
- Nombre de cases : 7, 9, 10, 12, 18
- Forme : droite, convexe, concave (gamme courbe)
- Avec/sans rainures
- Avec/sans colonne latérale

### Accessoires
- Banc (Berlin, Saphir 120, ou autres)
- Table de recueillement (IDEALO 2023)
- Monument central
- Jardinières

### Sol / Emprise
- Type de sol (rectangulaire, angle)
- Dimensions automatiques selon configuration

### Matériaux / Finitions
- Coloris granit (info non détaillée sur le site — à compléter avec CIMTEA)
- Type de portes

### Caveaux (option enterrée)
- Caveau polymère simple 27cm HT (avec/sans fond)
- Caveau polymère double 54cm HT
