Toujours mettre a jour les artefacts Scrumban (kanban-board.md, product-backlog.md) EN MEME TEMPS que le travail de dev, pas apres coup.

**Why:** Le stakeholder attend que le RACI soit respecte et que les documents refletent l'etat reel du projet a tout moment. Faire le dev puis oublier la doc cree un decalage.

**How to apply:** A chaque transition d'etat d'une US (To Do > In Progress > Testing > Done), mettre a jour immediatement le kanban et le backlog. Faire les deux dans le meme flux de travail que l'implementation.
