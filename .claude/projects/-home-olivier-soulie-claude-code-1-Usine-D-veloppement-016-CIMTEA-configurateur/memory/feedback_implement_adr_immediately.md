---
name: Implementer les ADR immediatement
description: Ne pas documenter une decision archi sans l'implementer dans la foulee
type: feedback
---

Quand un ADR est cree, l'implementer IMMEDIATEMENT apres, pas le laisser en attente.

**Why:** Le stakeholder a constate que l'ADR-002 (disposition pre-selectionnee) a ete documente puis oublie pendant qu'on faisait l'ADR-003 (topbar). Ca cree une incoherence visible dans le produit.

**How to apply:** ADR documente = implementation dans le meme flux. Ne pas passer a un autre sujet tant que l'ADR precedent n'est pas code.
